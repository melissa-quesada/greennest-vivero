# ⸙ GreenNest - Vivero Online

Landing page de e-commerce para una tienda de plantas, con navegación funcional, filtro de productos por categoría, carrito de compras interactivo y validación de formulario. Construida con HTML, CSS y JavaScript puro sobre Bootstrap 5.

## Tecnologías usadas
⸙ HTML5

⸙ CSS3

⸙ Bootstrap 5

⸙ Bootstrap Icons

⸙ JavaScript (Vanilla, sin frameworks)

## Funcionalidades
⸙ Navbar funcional con scroll suave a cada sección (Home, Shop, Plant Care, Contact)

⸙ Filtro de productos por categoría (All plants / New Arrivals / Sales / Easy Care), sin recargar la página

⸙ Carrito de compras con contador dinámico en el navbar, panel lateral (offcanvas) con resumen de productos, subtotal calculado en tiempo real, y opción de eliminar productos o vaciar el carrito

⸙ Validación de formulario en la sección de newsletter, con mensajes de éxito/error según el formato del correo ingresado

## Qué aprendí

Practiqué manipulación dinámica del DOM (crear y destruir elementos HTML según datos que cambian), manejo de arrays con métodos como find, filter y splice, y cómo re-conectar event listeners a elementos que se regeneran. También trabajé con expresiones regulares para validar el formato de un correo electrónico sin depender solo de la validación nativa del navegador.
